# Autotronics — Electrical & Electronics Fundamentals

Study notes generated from the L2 & L3 lecture (9 Aug 26), AELZG533/AEZG533
"Autotronics", Dr. Madhuri Bayya, BITS Pilani — built from the annotated
slide deck (117 slides) and the full class transcript.

## What's in this folder

```
autotronics-notes/
├── notes/            15 Markdown files — the actual study notes (read these
│                      directly in any Markdown viewer / editor / GitHub)
├── assets/img/        76 diagrams extracted from the lecture slides,
│                      referenced by the notes and the website
└── site/              A static website that renders the notes with
                        navigation, styling, and embedded diagrams
    ├── index.html      ← Open this file in a browser to start browsing
    ├── styles.css
    └── notes/          One HTML page per module
```

## How to use it

- **Just want to read/edit the notes as text?** Open anything in `notes/`
  — they're plain Markdown, viewable in any editor, Obsidian, GitHub, etc.
- **Want the nicer browsing experience?** Open `site/index.html` in a web
  browser (double-click it, or drag it into a browser tab). Use the
  sidebar to jump between the 14 modules; each page has prev/next links
  at the bottom. No internet connection or server required — it's fully
  self-contained (works offline, aside from optionally loading Google
  Fonts if you have a connection).
